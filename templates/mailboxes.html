Liaison Microsoft 365 à mettre en place

Les boîtes partagées sont dans Exchange Online. Pour que l'application puisse les lire et les modifier, lancez une fois le script de mise en place sur ce serveur :

  1. Ouvrez PowerShell en tant qu'administrateur sur le serveur de l'application.
  2. Lancez : powershell -ExecutionPolicy Bypass -File scripts\setup_m365.ps1 (depuis le dossier de l'application).
  3. Connectez-vous avec un compte Administrateur général Microsoft 365 quand la fenêtre s'ouvre.
  4. Rechargez cette page. Microsoft met parfois jusqu'à une heure à appliquer les droits.

Le script crée une application « AD Web Interface - Exchange » dans Entra ID, identifiée par un certificat conservé sur ce serveur (aucun mot de passe enregistré), avec le rôle « Administrateur des destinataires Exchange ». Pour tout retirer : supprimez l'application dans Entra ID.
